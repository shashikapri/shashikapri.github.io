How to Navigate the Chapter

US-1 Guidebook Navigation

Use the guide like a map

This chapter shows you how to move through the guidebook without reading everything in order. The chapters are arranged so you can start with the topic that matches your current need, then move forward or backward as your project situation changes.

Think of this as your fast track to the right section, checklist, or explanation.

Three simple ways to navigate

Start with the table of contents

Use the chapter list to find the section that matches your current task, question, or project phase.

Follow the chapter links

Use the previous and next buttons to move through related topics when you want a guided learning path.

Scan for purpose first

Read the heading, icons, and key callouts before you go into details so you can decide whether the chapter is relevant.

Best navigation habits

  • Read the short intro paragraph before diving into the main content.
  • Look for the practical takeaway or checklist in each chapter.
  • Jump to the chapter that matches your current project stage.
  • Return to earlier chapters whenever you need a refresher.

A quick reading flow

  1. Check the chapter title and user story badge.
  2. Read the intro to understand the chapter purpose.
  3. Skim the section headers and cards for the main ideas.
  4. Use the navigation buttons to continue or go back when needed.

Key takeaway: this guidebook is designed for selective reading, so you do not need to start from page one every time.
