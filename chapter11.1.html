Chapter 11.1

References and Citations

US-35 Academic Integrity

Use APA 7th edition consistently so the guidebook is credible, traceable, and free from plagiarism concerns.

User Story (US-35)

As a project manager, Scrum Master, or project team member, I want all sources to be clearly referenced and cited, so that the guidebook is credible and avoids plagiarism.

Why APA 7 Matters

APA 7 gives the guidebook a consistent way to show where ideas, facts, and best practices come from. That matters because readers can verify the source of a claim, follow the evidence, and trust that the material was prepared with care (American Psychological Association, 2020).

For a project management guidebook, clear citations also show which guidance comes from official standards, which comes from practitioner sources, and which is original explanation. That separation helps keep the content accurate and transparent (Project Management Institute, 2021).

In-Text Citation Rules

Narrative citation

Use the author name in the sentence when the source is part of the explanation.

Example: American Psychological Association (2020) explains that APA style uses author-date citations.

Parenthetical citation

Place the author and year in parentheses when the citation supports a sentence.

Example: Clear source tracking reduces plagiarism risk and improves trust (Project Management Institute, 2021).

Direct quotations

Use quotation marks only when the wording must stay exact, and include a page number when available.

Example: Use exact words sparingly; paraphrase more often than quoting.

Paraphrasing

Rewrite the idea in your own words and still cite the source.

Example: Good citation practice lets readers trace claims back to their original source.

Reference List Rules

  • Use author-date entries in alphabetical order by author.
  • Apply a hanging indent so the first line starts at the left margin and the following lines shift in.
  • Italicize book and report titles, but not article titles.
  • Include a DOI or URL when the reader needs to access the source online.
  • Use the organization name as author when no personal author is available.

Guidebook Standard

Source Type In-Text Example Reference Entry Pattern
Book (Project Management Institute, 2021) Author. (Year). Title (edition). Publisher.
Website (American Psychological Association, 2020) Organization. (Year). Page title. URL
Paraphrase in sentence American Psychological Association (2020) Same reference entry as above

Common Mistakes to Avoid

Missing citations

If a paragraph uses someone else’s idea, add a citation even when the wording is rewritten.

Inconsistent formatting

Keep the same capitalization, punctuation, and hanging-indent layout across every chapter.

Broken source trail

Make sure every in-text citation has a matching reference entry at the end of the chapter.

Summary: APA 7 keeps the guidebook readable and defensible. Use author-date citations in the text, then finish each chapter with a reference list that follows the same hanging-indent format.
